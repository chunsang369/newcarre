# ZeroCarz Clone (제로카즈 클론)

신차 장기렌트 및 리스 견적 비교 플랫폼을 1:1로 구현한 프로젝트입니다. 현재 데이터 소스를 '차살때' 플랫폼으로 완전히 이전하여, 250대 이상의 모든 차량 데이터를 100% 실데이터로 교체 및 최적화 완료했습니다.

## 최근 업데이트 내역 (Data Migration)

### 1. 차살때(Chasalddae) 데이터 1:1 완벽 이관 완료
- **데이터 파이프라인 재구축**: 기존 ZeroCarz 기반의 크롤링에서 차살때(Chasalddae)의 내부 Next.js RSC 페이로드를 역분석하여 파싱하는 동적 크롤링 시스템으로 전면 개편했습니다. (`rebuild_all_perfect2.js`)
- **250대 전 차종 1:1 매칭 완료**: 국산차 및 수입차 전체 250대 라인업에 대해 중복 데이터를 제거하고, 실제 트림명, 세부 옵션, 월 렌트/리스 가격을 100% 실제 데이터로 마이그레이션했습니다.

### 2. 차량 외장/내장 및 이미지 동기화
- **한글 파일명 인코딩 이슈 해결**: 로컬 이미지 에셋의 경우 한글 파일명으로 인한 브라우저 깨짐 현상을 방지하기 위해 정규식 영문 치환을 완벽히 적용하였습니다 (e.g. `hyundai-the-new-casper`).
- **CDN 의존성 제거**: 모든 썸네일 이미지를 로컬 `/public/images/cars/` 경로로 캐싱하여 빠른 로딩 속도와 안정성을 확보했습니다.
- **외장/내장 컬러 선택기**: 트림에 맞는 정확한 Hex 코드 배열을 추출하여 프론트엔드 컨피규레이터의 색상 탭과 1:1로 연동했습니다.

### 3. 고도화된 차량 컨피규레이터 (Configurator)
- **실제 견적 연동**: 임의의 수학적 공식(더미 가격)을 모두 제거하고, 차살때 원본에서 추출한 실제 월 렌트료(`monthlyRent`)와 리스료(`monthlyLease`)를 `priceMatrix`의 기본값(`36_PREPAY_30_20000`)에 직접 바인딩하여 100% 동일한 견적을 산출합니다.

### 4. UI/UX 고도화 및 가격 로직 최적화 (2024-05-14)
- **미니멀리즘 디자인 적용**: 컨피규레이터의 불필요한 테두리(`border`), 그림자(`shadow`), 구분선을 모두 제거하여 '차살때' 스타일의 깔끔하고 세련된 화이트 톤 UI를 완성했습니다.
- **캐스퍼 일렉트릭 가격 정상화**: 보조금 산정 로직(`subsidyFactor`)을 정밀하게 적용하여, 비정상적으로 높거나 낮게 표시되던 캐스퍼 일렉트릭의 월 리스료를 실제 시장가(70,200원~)에 맞게 100% 동기화했습니다.
- **메인 페이지 가격 정합성**: 목록 페이지(Car Card)에도 동일한 보조금 및 할인 로직을 적용하여 전체 플랫폼의 견적 신뢰도를 확보했습니다.

### 5. 검색 고도화 및 홈 UI 심플화 (2024-05-15)
- **수입차 한국어 검색어 확장**: 5시리즈, e클래스, 폴스타4 등 한국어 대중 명칭으로 검색해도 영문 DB를 자동 매칭하여 정확히 검색되도록 내부 키워드 맵을 도입했습니다.
- **관심차종 UI 심플화**: "이차 간편 견적은?"으로 직관적 헤더를 수정하고 모바일 환경에서는 시야 확보를 위해 우측 그라데이션 페이드아웃 오버레이를 숨김 처리했습니다.

### 6. 견적 안내방법 중복선택 및 로고 버그 수정 (2026-05-18)
- **안내방법 & 상담 가능 시간 다중 선택 지원**: 기존 단일 선택(라디오 버튼)에서 여러 채널 및 시간대를 동시에 선택할 수 있도록 다중 체크박스 형태로 개편하고 데이터 직렬화 형식을 보존했습니다.
- **모바일/메인 화면 로고 내비게이션 개선**: 모바일 메뉴바와 메인 화면 전체에서 로고 클릭 시 홈 페이지('/')로 즉각적이고 안정적인 내비게이션이 작동하도록 개선했습니다.
- **어드민 디테일 및 리스트 가독성 향상**: DB에 저장된 다중 선택값(예: `["kakao", "phone"]`)을 직관적인 한국어 텍스트(예: `카카오톡, 전화`)로 매핑하여 리스트 및 상세 페이지에서 깔끔하게 출력합니다.


## 기술 스택
- **Frontend**: Next.js 15 (App Router), Tailwind CSS
- **Backend**: Prisma, PostgreSQL (Neon DB)
- **Automation**: Node.js, Axios, 정규식 기반 RSC 페이로드 디코딩

## 배포 및 실행 가이드
본 프로젝트는 Netlify를 통해 배포되며, 아래 스크립트로 안전한 클린 빌드가 가능합니다.
```bash
npm ci && npm run build
```
