# ZeroCarz Clone (제로카즈 클론)

신차 장기렌트 및 리스 견적 비교 플랫폼을 1:1로 구현한 프로젝트입니다. 현재 데이터 소스를 '차살때' 플랫폼으로 완전히 이전하여, 250대 이상의 모든 차량 데이터를 100% 실데이터로 교체 및 최적화 완료했습니다.

## 최근 업데이트 내역 (Data Migration)

### 1. 차살때(Chasalddae) 데이터 1:1 완벽 이관 완료
- **데이터 파이프라인 재구축**: 기존 ZeroCarz 기반의 크롤링에서 차살때(Chasalddae)의 내부 Next.js RSC 페이로드를 역분석하여 파싱하는 동적 크롤링 시스템으로 전면 개편했습니다. (`rebuild_all_perfect2.js`)
- **250대 전 차종 1:1 매칭 완료**: 국산차 및 수입차 전체 250대 라인업에 대해 중복 데이터를 제거하고, 실제 트림명, 세부 옵션, 월 렌트/리스 가격을 100% 실제 데이터로 마이그레이션했습니다.

### 2. 차량 외장/내장 및 이미지 동기화
- **한글 파일명 인코딩 이슈 해결**: 로컬 이미지 에셋의 경우 한글 파일명으로 인한 브라우저 깨짐 현상을 방지하기 위해 정규식 영문 치환을 완벽히 적용하였습니다 (e.g. `hyundai-the-new-casper`).
- **CDN 의존성 제거**: 모든 썸네일 이미지를 로컬 `/public/images/cars/` 경로로 캐싱하여 빠른 로딩 속도와 안정성을 확보했습니다.
- **외장/내장 컬러 선택기**: 트림에 맞는 정확한 Hex 코드 배열을 추출하여 프론트엔드 컨피규레이터의 색상 탭과 1:1로 연동했습니다.

### 3. 고도화된 차량 컨피규레이터 (Configurator)
- **실제 견적 연동**: 임의의 수학적 공식(더미 가격)을 모두 제거하고, 차살때 원본에서 추출한 실제 월 렌트료(`monthlyRent`)와 리스료(`monthlyLease`)를 `priceMatrix`의 기본값(`36_PREPAY_30_20000`)에 직접 바인딩하여 100% 동일한 견적을 산출합니다.

### 4. UI/UX 고도화 및 가격 로직 최적화 (2024-05-14)
- **미니멀리즘 디자인 적용**: 컨피규레이터의 불필요한 테두리(`border`), 그림자(`shadow`), 구분선을 모두 제거하여 '차살때' 스타일의 깔끔하고 세련된 화이트 톤 UI를 완성했습니다.
- **캐스퍼 일렉트릭 가격 정상화**: 보조금 산정 로직(`subsidyFactor`)을 정밀하게 적용하여, 비정상적으로 높거나 낮게 표시되던 캐스퍼 일렉트릭의 월 리스료를 실제 시장가(70,200원~)에 맞게 100% 동기화했습니다.
- **메인 페이지 가격 정합성**: 목록 페이지(Car Card)에도 동일한 보조금 및 할인 로직을 적용하여 전체 플랫폼의 견적 신뢰도를 확보했습니다.

### 5. 검색 고도화 및 홈 UI 심플화 (2024-05-15)
- **수입차 한국어 검색어 확장**: 5시리즈, e클래스, 폴스타4 등 한국어 대중 명칭으로 검색해도 영문 DB를 자동 매칭하여 정확히 검색되도록 내부 키워드 맵을 도입했습니다.
- **관심차종 UI 심플화**: "이차 간편 견적은?"으로 직관적 헤더를 수정하고 모바일 환경에서는 시야 확보를 위해 우측 그라데이션 페이드아웃 오버레이를 숨김 처리했습니다.

### 6. 견적 안내방법 중복선택 및 로고 버그 수정 (2026-05-18)
- **안내방법 & 상담 가능 시간 다중 선택 지원**: 기존 단일 선택(라디오 버튼)에서 여러 채널 및 시간대를 동시에 선택할 수 있도록 다중 체크박스 형태로 개편하고 데이터 직렬화 형식을 보존했습니다.
- **모바일/메인 화면 로고 내비게이션 개선**: 모바일 메뉴바와 메인 화면 전체에서 로고 클릭 시 홈 페이지('/')로 즉각적이고 안정적인 내비게이션이 작동하도록 개선했습니다.
- **어드민 디테일 및 리스트 가독성 향상**: DB에 저장된 다중 선택값(예: `["kakao", "phone"]`)을 직관적인 한국어 텍스트(예: `카카오톡, 전화`)로 매핑하여 리스트 및 상세 페이지에서 깔끔하게 출력합니다.

### 7. 속도 최적화 및 서버리스 아키텍처 개선 (2026-05-19)
- **Neon DB HTTP 드라이버 전환**: 서버리스 환경의 커넥션 고갈을 방지하기 위해 TCP 방식에서 `@prisma/adapter-neon` HTTP 드라이버로 전환하고 싱글톤 연결 패턴을 정교화했습니다.
- **태그 기반 ISR 캐싱 도입**: 모든 데이터 조회에 `unstable_cache`를 적용하고 태그(`cars`, `reviews`, `faq`) 기반 캐시 레이어를 구축해 응답 지연을 획기적으로 줄였습니다.
- **온디맨드 revalidateTag 연동**: 어드민에서 데이터를 추가/수정/삭제 시 `revalidateTag`를 실행하여 캐시를 실시간으로 즉시 갱신하도록 설계했습니다.
- **React Suspense & Skeleton 스트리밍**: 메인 페이지의 FAQ, 후기 목록 및 각 서브 페이지(`/cars`, `/cars/[carId]`, `/reviews`, `/faq`)에 유려한 스켈레톤 로딩 가이드와 `Suspense`를 결합하여 프리미엄 급 웹 속도 체감을 제공합니다.
- **LCP 및 쿼리 최적화**: 메인 히어로 이미지와 썸네일에 `fetchPriority="high"` 및 `priority`를 강제 적용하였고, 차량 리스트 조회 시 무거운 필드(옵션 JSON 등)를 `select` 구문으로 제외하여 데이터 페이로드 크기를 2MB 이하로 경량화했습니다.
- **웜업 핑(Warming Ping) 보안 엔드포인트 구현**: `/api/health`를 통해 Neon DB 커넥션 상태를 점검할 수 있는 보안 토큰 검증형 웜업 인터페이스를 마련했습니다.

### 8. 통합 인기차(PopularCar) DB 구축 및 UX 단선화 (2026-05-21)
- **통합 인기차 DB 구축**: 국산/수입 구분을 배제하고 실 판매량 순위(쏘렌토, Model Y, 그랜저 등)에 근거한 Top 10 인기차 데이터베이스(`PopularCar` 모델)를 구축하고 실제 랭킹 변동 데이터를 포함해 시드 작업을 완료했습니다.
- **기본 모델 기준 적용**: 인기차 순위를 하이브리드(HEV) 변형이 아닌 기본 모델 기준으로 매핑하여 고객이 가장 먼저 접하는 차량이 표준 라인업이 되도록 조정했습니다.
- **ALL 탭 대체 및 고객 동선 최소화**: 빠른 간편 견적의 브랜드 선택 캐러셀에서 단순 나열에 가까웠던 "ALL(전체)" 탭을 완전히 삭제하고, 해당 영역에 "인기차(POPULAR)" 통합 탭을 전면 배치함으로써 고객 이탈율을 줄이고 빠른 견적 신청 경로를 확보했습니다.
- **프리미엄 랭킹 배지 UI**: 1위부터 10위까지의 인기 차량에 대해 카드 좌상단에 프리미엄 그라데이션 디자인의 '🔥 N위' 뱃지를 유려하게 출력하여 시각적 직관성과 Wow 요소를 극대화했습니다.

### 9. Hydration Mismatch 해결 및 프리미엄 캐러셀 고도화 (2026-05-21)
- **SSR/CSR Hydration Mismatch 근원 해결**: 인라인 `style` 속성(`touchAction`, `transform`)이 서버와 클라이언트 간에 camelCase/kebab-case 불일치를 발생시키는 문제를 Tailwind CSS 유틸리티 클래스(`touch-pan-y`, `scale-[1.15]`)로 전면 대체하여 원천 제거했습니다.
- **브라우저 확장 프로그램 오염 정화**: 드래그 해제 확장 프로그램이 DOM에 강제 주입하는 `user-select: auto` 스타일을 React Hydration 이전에 초정밀 MutationObserver로 실시간 감지·제거하는 정화 엔진을 구축했습니다.
- **지능형 에러 오버레이 시스템**: 확장 프로그램 관련 Hydration 경고만 선별 차단하고, 실제 소스코드 오류(`TypeError`, `SyntaxError` 등)의 Next.js 개발 오버레이는 정상 노출되도록 보장하는 지능형 필터링 아키텍처를 완성했습니다.
- **프리미엄 마그네틱 스냅 캐러셀**: Embla Carousel의 `dragFree`를 비활성화하고 `duration` 스무딩을 적용하여 카드가 정렬선에 자석처럼 정확히 걸리는 유려한 슬라이딩 경험을 제공합니다.
- **네이티브 드래그 고스트 박스 차단**: `onDragStart` 가로채기와 `draggable={false}` 속성으로 마우스 드래그 시 발생하던 브라우저 링크 프리뷰 툴팁 박스를 완벽하게 제거했습니다.

### 10. 어드민 요금 관리 센터 구축 및 미시적 일괄 요금 수정 (2026-06-08)
- **전역 요금 일괄수정 & 복원**: 모든 차량의 렌탈/리스 조건별 요금제 가격에 가감 연산(+/- 원화)을 일괄 적용하고, 최초 시드 데이터(`car-data.ts`) 상태로 한 번에 복원할 수 있는 API를 구축했습니다.
- **정밀 조건부 일괄수정**: 일괄수정 시 브랜드, 모델뿐만 아니라 특정 가격 대역(예: 10만원대 요금제만)을 타겟팅하여, 차량 내 27개 매트릭스 중 조건에 부합하는 개별 가격 항목만 선택적으로 가감하는 미시적 요금 조정 시스템을 개발했습니다.
- **동적 10만원 단위 대역 분류**: 차량 가격 분포의 렌트/리스 원가를 실시간 연산하여 10만원 단위의 탭(10만원대 ~ 130만원대 이상)을 동적으로 생성하고, 원가를 고정 기준 삼아 필터링을 적용하는 견고한 분류 방식을 도입했습니다.
- **세부 매트릭스 편집 모달**: 기간(36/48/60개월), 보증조건(무보증/보증금/선수금), 주행거리별 렌트료/리스료 54개 조합을 직관적인 그리드 테이블 모달을 통해 각각 상세 편집할 수 있도록 구현했습니다.

### 11. 특정 차량 요금 인상 반영 (2026-07-20)
- **캐스퍼 EV 요금 인상**: 현대 캐스퍼 EV(캐스퍼 일렉트릭)의 월 대여료(렌트/리스)를 전체적으로 기존 대비 2.0배 수준으로 일괄 인상 조정하였습니다.
- **테슬라 모델 Y & 모델 3 요금 인상**: 테슬라 모델 Y(RWD, Long Range) 및 모델 3 전 라인업(총 5개 슬러그)의 월 렌트/리스 요금을 일괄적으로 30,000원씩 인상 반영하였습니다.

### 13. 제트카 저신용 장기렌트 실거래가 매핑 및 UX 고도화 (2026-08-24)
- **제트카 저신용 실거래가 100% 동기화**: 제트카(jetcar.co.kr)의 기아차 및 전 차종 무심사 저신용 실거래 월 렌트료 데이터를 정밀 크롤링하여 저신용 장기렌트 페이지(`/low-credit`)에 1:1 완벽 매칭했습니다.
- **메인 히어로 롤링 캐러셀 배너 탑재**: 메인 홈 화면 최상단에 6초 주기 자동 롤링 히어로 배너를 도입하여 1번 메인 비디오 배너와 2번 무심사 저신용 전용 배너를 유려하게 전환합니다.
- **일반 신차 [견적보기] 및 [빠른상담] 분리**: 메인 및 전체 차량 카드에서 상세 견적 계산기(`/cars/[slug]`)로 이동하는 [견적보기]와 간편 신청서로 즉시 스크롤되는 [빠른상담]을 명확히 분리 제공합니다.
- **간편 견적문의 [무심사희망] 배지 및 자동 기재**: 저신용 페이지에서 견적 신청 시 폼 상단에 파란색 `[무심사희망]` 배지와 상세 차종명이 자동으로 세팅되어 고객 의도를 명확히 식별합니다.
- **고해상도 표준 OG 이미지 및 네이버 스크랩 최적화**: 네이버 카페, 블로그, 카카오톡 등에 링크 공유 시 거대한 제조사 로고 대신 1200×630 규격의 정갈하고 세련된 제로카즈 공식 썸네일(`public/og-image.png`)이 노출되도록 메타데이터를 전면 개편했습니다.
- **모바일 뷰포트 레이아웃 최적화**: 모바일 세로 화면에서 선물박스 내부 차량 실루엣이 한눈에 들어오도록 배경 초점(68%)을 조정하고, 하단 컨트롤러를 가로형 와이드 캡슐 디자인으로 변경하여 글자 찌그러짐을 완벽히 해결했습니다.

## 기술 스택
- **Frontend**: Next.js 16 (App Router), Tailwind CSS
- **Backend**: Prisma, PostgreSQL (Neon DB)
- **Automation**: Node.js, Axios, Playwright, 정규식 기반 RSC 페이로드 디코딩
